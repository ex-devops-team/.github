# Contributing

Thank you for helping improve the project.

## Before you start

- Check the repository README, open issues, and repository-specific instructions.
- For a substantial change, open an issue first so scope and compatibility can be agreed.
- Do not submit secrets, credentials, personal data, confidential material, or code you are not authorized to contribute.
- Preserve copyright, license, attribution, and notice files for third-party material.
- A repository may have additional publication or legal restrictions even when this default guide is visible.

## Pull requests

Keep changes focused and explain why they are needed. Include tests or validation appropriate to the change, update documentation, and describe compatibility or operational impact. A pull request is not considered ready until its checks pass and the repository owner has reviewed it.

By contributing, you confirm that you have the right to submit the contribution under the licensing terms stated by the target repository. If the repository has no license, ask the owner before contributing.

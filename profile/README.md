# Development Platform Engineering

We design and maintain reusable building blocks for engineering platforms: delivery tooling, infrastructure automation, observability, artifact management, container foundations, and platform security.

## What we work on

- Developer platform architecture and reusable contracts
- CI/CD and secure software delivery
- Kubernetes, Helm, Terraform, and infrastructure automation
- Observability and operational tooling
- Artifact management and software supply-chain security
- Minimal and distroless container foundations

## Public projects

- [distroless](https://github.com/ex-devops-team/distroless) — experiments and reference material for minimal container runtimes.
